# 文档索引

这个目录是项目文档中心。

## 从这里开始

- `product/scope.md`：AgentBot 当前“要做什么、不做什么”
- `product/roadmap.md`：已经完成的里程碑与下一步方向
- `architecture/index.md`：系统架构总览
- `runbooks/local-dev.md`：本地运行与开发方式

## 文档地图

- `architecture/`
  - 系统结构
  - graph flow
  - persistence model
- `product/`
  - scope
  - roadmap
- `exec-plans/active/`
  - 正在执行的实现计划
- `exec-plans/completed/`
  - 已完成阶段归档
- `decisions/`
  - 重要技术决策
- `runbooks/`
  - 本地开发、配置、调试说明

## 维护规则

当代码行为发生变化时，优先更新这里对应的文档，而不是在别处补零散说明。
