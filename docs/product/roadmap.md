# 产品 Roadmap

## 当前状态

当前代码已经完成了项目的第一大阶段：

- project skeleton
- minimal agent loop
- default conversation persistence
- framework hardening
- conversation meta 和 local execution logs

## 当前建议方向

在保持现有 graph shape 和本地 persistence model 不变的前提下，下一步最自然的方向是扩展工具能力。

## 近期里程碑

1. richer tools
2. 更强的 persistence 与 checkpointer 支持
3. API server
4. execution log visualization
5. long-term memory
6. subgraph 或 multi-agent 实验

## 规划规则

Roadmap 只表达产品方向。

具体实现工作应落到 `docs/exec-plans/active/` 中。
